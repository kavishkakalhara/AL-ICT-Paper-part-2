මුලින්ම මතක තියාගන්න core 5

  1. දත්ත (Data) = අමු/සකස් නොකළ සත්‍යයන් (raw facts) → උදා: "75". තොරතුරු (Information) = සකස් කරලා අර්ථයක් ආපු දත්ත → උදා: "පාඩම 3ට ලකුණු 75"
  2. දත්ත ජීවන චක්‍රය: නිර්මාණය → කළමනාකරණය → අභාවිත දත්ත ඉවත් කිරීම
  3. වියුක්ත ආකෘතිය (abstract model): ආදාන (Input) → සැකසුම (Process) → ප්‍රතිදාන (Output)
  4. වටිනා තොරතුරුවල ලක්ෂණ: කාලෝචිත, නිරවද්‍ය, සම්පූර්ණ, අදාළ, අඩු අනිශ්චිතතාව
  5. දත්ත සැකසීමේ අදියර 5: රැස්කිරීම → වලංගුකරණය → සැකසුම → ප්‍රතිදානය → ගබඩා කිරීම

  • Presence Check — හිස්ව තියලා තියෙනවද?
  • Range Check — නියම පරාසය ඇතුළේද? (0–100)
  • Format Check — ආකෘතිය හරිද? (දිනය DD/MM/YYYY)

💡 Verification (දෙපාරක් ඇතුළත් කරලා සසඳනවා) vs Validation (නීතිවලට අනුකූලද) — මේ වෙනස අහනවා.

🧠 මතක ක්‍රම — Validation types

"ටී පී ආර් එෆ්" = Type · Presence · Range · Format. "අට පිට රිෆ්" කියලා කටපාඩම් කරන්න.

🎯 ප්‍රශ්න එන විදිය

සාමාන්‍යයෙන් A කොටසේ Q1 විදියට: "දත්ත vs තොරතුරු උදාහරණ 2කින්", "ජීවන චක්‍රයේ අදියර නම් කරන්න", "මේ validation type එක මොකක්ද", "ICT යොදන ක්ෂේත්‍ර 3ක් + උදාහරණ" වගේ කෙටි ප්‍රශ්න.

3️⃣ පාඩම 3 — දත්ත නිරූපණය (Data Representation)

සංඛ්‍යා පද්ධති 4

🧮 Universal ක්‍රමය 1 — ඕනම base එකක් → දශම (Decimal)

සෑම ඉලක්කමක්ම එහි ස්ථාන අගය (base^position) එකෙන් ගුණ කරලා එකතු කරන්න.

උදා: (1011)₂ = 1×2³ + 0×2² + 1×2¹ + 1×2⁰ = 8+0+2+1 = 11
උදා: (2F)₁₆ = 2×16¹ + 15×16⁰ = 32 + 15 = 47
🧮 Universal ක්‍රමය 2 — දශමය → ඕනම base එකක්

නැවත නැවත base එකෙන් බෙදලා ඉතුරු (remainders) පහළ සිට උඩට ලියන්න.

25 ÷ 2 = 12, ඉතුරු 1
12 ÷ 2 = 6, ඉතුරු 0
6 ÷ 2 = 3, ඉතුරු 0
3 ÷ 2 = 1, ඉතුරු 1
1 ÷ 2 = 0, ඉතුරු 1 → නවතිනවා
පහළ සිට උඩට: (11001)₂ ✅
🧮 Universal ක්‍රමය 3 — Binary ↔ Octal / Hex (කෙටිම මාර්ගය)

Octal: binary එක 3 bit ගානේ දකුණේ ඉඳන් කඩන්න. Hex: 4 bit ගානේ කඩන්න.

(110010)₂ → Hex: 0011 0010 = (32)₁₆
(110010)₂ → Octal: 110 010 = (62)₈
🧮 Universal ක්‍රමය 4 — ඍණ සංඛ්‍යා (2's Complement) — නිතරම එනවා

ධන අගය → binary → සියලු bits invert කරන්න → +1 කරන්න.

−5 ගන්න 8-bit වලින්. 5 = 00000101
Invert: 11111010
+1: 11111011 ✅ උත්තරය

💡 1's complement = invert විතරයි (+1 නෑ). Sign & Magnitude = මුල්ම bit එක sign (1=ඍණ), ඉතුරු ඒවා magnitude.

අක්ෂර කේතන (Character encoding)

  • ASCII: ඇමරිකානු සම්මතය, 7-bit (128) / extended 8-bit (256).
  • EBCDIC: IBM වල පරණ 8-bit කේතය.
  • Unicode: සෑම භාෂාවකම අකුරු cover කරනවා — UTF-8 වැනි.
🧠 මතක ක්‍රම

BCD = එක් එක් decimal ඉලක්කම 4-bit binary වලින්. "ඉලක්කමෙන් ඉලක්කමට 4 bit".

Bit→Byte: 8 bit = 1 byte. KB→MB→GB→TB: එක එකක් 1024 ගුණයක්.

4️⃣ පාඩම 4 — අංකිත පරිපථ / තාර්කික ද්වාර (Logic Gates)

B කොටස essay · ලකුණු ~15 · practice කළොත් full marks ගන්නම පුළුවන්

ද්වාර 7 + ඒවායේ truth tables

Gateසිංහලඅදහස / සූත්‍රයඅමතක නොවන tip
ANDහාA·B — දෙකම 1 නම් විතරක් 1ගුණ කිරීම වගේ (0×ඕනම = 0)
ORහෝA+B — එකක් හරි 1 නම් 1එකතු කිරීම වගේ
NOTනොවĀ — උඩු යටිකුරුinverter
NAND—NOT of ANDAND එකේ output එක flip
NOR—NOT of OROR එකේ output එක flip
XOR—A⊕B — දෙක වෙනස් නම් 1"එක්කෙනෙක් 1 නම් 1"
XNOR—NOT of XOR — දෙක සමාන නම් 1"සමාන = 1"
🧠 truth table ලියන ක්‍රම (මතකයෙන්ම)

2 inputs → පේළි 4: 00, 01, 10, 11. 3 inputs → පේළි 8: 000…111. ඉලක්කම් 0 සිට උඩට ගණන් කරනවා වගේ.

AND: 0001 · OR: 0111 · NAND: 1110 · NOR: 1000 · XOR: 0110 · XNOR: 1001

Universal gates

NAND සහ NOR universal — ඒ දෙකෙන් ඕනම gate එකක් හදන්න පුළුවන්. ප්‍රශ්නේ: "NAND වලින් AND/OR/NOT හදන්න" — මේක අඳින්න පුරුදු වෙන්න.

Boolean algebra + De Morgan

De Morgan:  (A+B)' = A'·B'     සහ     (A·B)' = A' + B'
  • SOP = Sum of Products (OR of ANDs) — truth table එකේ 1 තියෙන පේළි අරගෙන.
  • POS = Product of Sums (AND of ORs) — 0 තියෙන පේළි අරගෙන.
🧮 K-map කරන Universal ක්‍රමය
Variable ගණන අනුව grid එක හදන්න: 2 var → 2×2, 3 var → 2×4, 4 var → 4×4.
Truth table එකේ 1 ටික කොටුවලට දාන්න.
අසල්වැසි 1 ටික 2,4,8 ගානේ (power of 2) loop කරන්න — විශාලම loop, හැකි තරම් අඩු loop ගණන.
එක් එක් loop එකෙන් වෙනස් නොවන variable ටික විතරක් ගන්න (වෙනස් වෙන ඒවා අයින්).
Loop terms ටික OR (+) කරලා ලියන්න → සුළු කළ expression.

Combinational + Sequential

  • Half Adder: Sum = A⊕B, Carry = A·B. Full Adder = carry-in එකත් ගන්නවා.
  • Flip-flops (SR, JK, D): මතකයක් තියෙනවා (1 bit store). SR: S=1,R=0→Set, S=0,R=1→Reset, S=R=1 invalid.
  • Encoder/Decoder, MUX/DEMUX: කෙටි විස්තරයක් + diagram විතරක් මතක තියාගන්න.

5️⃣ පාඩම 5 — පරිගණක මෙහෙයුම් පද්ධති (OS)

B කොටස essay · ලකුණු ~15 · 2023දී paging + FAT ආවා — ඒ දිශාවට හොඳටම පාඩම් කරන්න

OS කාර්යයන් (කෙටියෙන් ලියන්න ඕන)

  • මතක කළමනාකරණය · process scheduling · file කළමනාකරණය · device/I/O කළමනාකරණය · ආරක්ෂාව · user interface

Process + Scheduling

  • PCB (Process Control Block): process එකක් ගැන තොරතුරු (ID, state, registers, memory info) තියෙන block එක.
  • Process states: New → Ready → Running → Blocked/Waiting → Terminated
  • Scheduling algorithms:
    • FCFS — ආපු පිළිවෙළට
    • SJF — කෙටිම job එක මුලින්
    • Round Robin — time slice (quantum) එකක් එකක්ට
    • Priority — ඉහළම priority එක මුලින්
🧮 Paging — Universal ක්‍රමය (2023 pattern)

තාර්කික ලිපිනය = page number + offset. Physical = frame number + offset (offset වෙනස් වෙන්නේ නෑ).

Page size එකෙන් logical address එක බෙදන්න: page = address ÷ pageSize, offset = address % pageSize.
Page table එකෙන් ඒ page එකට අදාළ frame number එක හොයන්න.
Physical = frame × pageSize + offset.
උදා: page size = 4KB, address = 4097 → page = 1, offset = 1
page 1 → frame 3 නම්, physical = 3×4096 + 1

💡 Fragmentation: Internal = block/page එක ඇතුළේ නාස්ති ඉඩ. External = free ඉඩ කැබලි වෙලා තියෙන එක.

🧮 FAT — File Allocation Table (2023 pattern)

FAT entry එකක් = ඊළඟ block number. −1/EOF = file එකේ අවසාන block එක. Directory entry = පළමු block number.

Directory entry එකෙන් මුල් block එක ගන්න.
FAT එකෙන් ඒ block එකේ entry එක බලලා ඊළඟ block එක හොයන්න.
EOF/−1 හම්බවෙනකම් chain එක යන්න → ඒක තමයි file එකේ block ලැයිස්තුව.

OS වර්ග + වෙනත්

  • Batch, Time-sharing, Real-time, Distributed, Network, Mobile
  • Virtual memory = RAM එක මදි වුණාම disk එකෙන් කොටසක් RAM වගේ පාවිච්චි කිරීම.
  • Deadlock = processes දෙකක් එකිනෙකාගේ resources බලාගෙන හිරවෙන තත්ත්වය.

6️⃣ පාඩම 6 — දත්ත සන්නිවේදනය හා ජාලකරණය (Networking)

B කොටස essay · ලකුණු ~14-15 · subnetting එක්ක practice කරන්න

මූලික සංකල්ප

  • දිශාවන්: Simplex (එක පැත්තකට), Half-duplex (දෙපැත්තටම, එක වරකට එක), Full-duplex (දෙකම එකවර)
  • මාධ්‍ය: Guided (twisted pair, coaxial, fibre) / Unguided (radio, microwave, satellite, Wi-Fi)
  • Network වර්ග: PAN, LAN, MAN, WAN
  • Topologies: Star, Bus, Ring, Mesh — වාසි/අවාසි 2ක් බැගින් ලියන්න පුළුවන් වෙන්න

උපාංග (device roles) — නිතර එන table

උපාංගයකාර්යය

OSI model — 7 layers (උඩ ඉඳන් පහළට මතකයට)

🧠 මතක ක්‍රම

"All People Seem To Need Data Processing" = Application → Presentation → Session → Transport → Network → Data link → Physical.

IP addressing + Subnetting — ලොකුම ගණන්

  • IP = තාර්කික ලිපිනය (network තුළ). MAC = භෞතික ලිපිනය (NIC එකේම තියෙන, වෙනස් කරන්න බෑ).
  • CIDR /26 = subnet mask 255.255.255.192 (host bits 6ක්).
🧮 Subnetting — Universal ක්‍රමය
Subnet mask / prefix එකෙන් host bits ගණන හොයන්න: /26 → 32−26 = 6 host bits.
Hosts per subnet = 2⁶ − 2 (= 62). (−2 = network + broadcast ලිපින)
Subnet ගණන = 2^(ණයට ගත් bit ගණන). Block size = 2^host bits.
Network address = IP එක AND block ගණන්කඩ. Broadcast = subnet එකේ අන්තිම address. Usable = ඒ දෙක අතර.
192.168.56.32/26 → block size 64
Subnets: 192.168.56.0, .64, .128, .192
.32 කියන්නේ .0 subnet එක ඇතුළේ (network .0, broadcast .63, usable .1–.62)

Protocols + switching

  • TCP — reliable, connection-oriented · UDP — වේගවත්, connectionless
  • HTTP (web), FTP (file), SMTP (mail send), POP3/IMAP (mail receive), DHCP (IP දීම), DNS (නම→IP)
  • Circuit switching = කලින්ම path එකක් වෙන් කරනවා (දුරකථන). Packet switching = දත්ත කැබලිවලට කඩලා වෙන වෙනම යවනවා (internet).
  • Error detection: Parity bit, Checksum, CRC.

7️⃣ පාඩම 7 — පද්ධති විශ්ලේෂණය හා පිරිසැලසුම (Systems Analysis & Design)

A කොටස Q2 (අනිවාර්ය) · ලකුණු ~10

SDLC අදියර 7 (පිළිවෙළ මතක තියාගන්න)

🧠 මතක ක්‍රම

"ෆී ඇන ඩිස් දෙව් ටෙස් ඉම්ප් මේන්" = Feasibility → Analysis → Design → Development → Testing → Implementation → Maintenance.

ශක්‍යතා අධ්‍යයනය (Feasibility) — TELOS

  • Technical — තාක්ෂණිකව කරන්න පුළුවන්ද
  • Economic — මුදල් වාසිදායකද (cost-benefit)
  • Legal — නීතිමය
  • Operational — සංවිධානයට/සේවකයන්ට ගැලපේද
  • Schedule — නියමිත වෙලාවට ඉවර කරන්න පුළුවන්ද

කරුණු රැස්කිරීමේ ක්‍රම 4

Interview (සම්මුඛ) · Questionnaire (ප්‍රශ්නාවලිය) · Observation (නිරීක්ෂණ) · Document review (ලේඛන පරීක්ෂාව)

DFD (Data Flow Diagram) — ඇඳීම අනිවාර්ය

✏️ DFD අඳින 4 symbols
  • කවය (Process) — දත්ත සකසන තැන
  • ඊතලය (Data flow) — දත්ත ගලායාම
  • සෘජුකෝණය (External entity) — පද්ධතියෙන් පිට source/destination (පුද්ගලයෙක්, ආයතනයක්)
  • විවෘත සෘජුකෝණය / parallel lines (Data store) — D1, D2 වගේ ගබඩා

Level 0 (Context) = මුළු පද්ධතියම එක process එකක්. Level 1 = process ටික වෙන් කරලා.

Implementation (changeover) ක්‍රම + COTS

  • Direct — පරණ එක නවත්වලා අලුත් එකම (අවදානම්)
  • Parallel — දෙකම ටික කාලයක් එකට (ආරක්ෂිත, මිල අධික)
  • Phased — කොටස් වශයෙන්
  • Pilot — එක අංශයක මුලින්ම try කරනවා

COTS (Commercial Off-The-Shelf) = කඩෙන් ගන්න පුළුවන් සූදානම් මෘදුකාංග. Custom = අවශ්‍යතාවටම හදන එක.

8️⃣ පාඩම 8 — දත්ත සමුදාය කළමනාකරණය (Database)

B කොටස essay · ලකුණු ~14.5 · SQL + Normalization = අනිවාර්ය

Keys

  • Primary key — record එකක් අනන්‍යව හඳුනන field එක
  • Foreign key — වෙනත් table එකක primary key එකට යොමු වෙන field එක
  • Composite key — fields කිහිපයක් එකතු වෙලා
  • Candidate key — primary key වෙන්න සුදුසුකම් තියෙන හැම එක

ER diagram — අඳින symbols

  • Entity = සෘජුකෝණය · Attribute = ඉලිප්සය (ellipse) · Relationship = දියමන්තිය (diamond)
  • Cardinality: 1:1, 1:M, M:N

Normalization — 1NF → 2NF → 3NF

🧮 Universal ක්‍රමය (step by step)
1NF: සෑම cell එකකම එක atomic value එකයි තියෙන්න ඕන — repeating groups අයින් කරන්න.
2NF: 1NF + composite key එකක partial dependency (key එකේ කොටසකට විතරක් රඳා පවතිනවා) අයින් කරන්න.
3NF: 2NF + transitive dependency (key නොවන field එකකින් තවත් key නොවන field එකක් රඳා පවතිනවා) අයින් කරන්න.

SQL — හැමදාම එන command pattern

SELECT column(s)
FROM table
WHERE condition
ORDER BY column ASC|DESC
GROUP BY column
HAVING condition
LIMIT n;
කාර්යයSQL
දත්ත ගන්නSELECT * FROM Employee WHERE Department='IT';
ඇතුළත් කරන්නINSERT INTO Employee VALUES (...);
වෙනස් කරන්නUPDATE Employee SET Salary=107000 WHERE Emp_ID='E110';
මකන්නDELETE FROM Employee WHERE Emp_ID='E111';
එකතු කරන්න (table)CREATE TABLE ...;
🧠 මතක ක්‍රම

SELECT එකේ order: "S-F-W-G-H-O" = SELECT → FROM → WHERE → GROUP BY → HAVING → ORDER BY. කටපාඩම්: "සල්ලි ෆ්‍රොම් වෙලාවට ගෙදර හවසට ඕඩර්" 😄

පාඩම 11 — IoT (Internet of Things)

  • E-commerce models: B2B (ව්‍යාපාර↔ව්‍යාපාර), B2C (ව්‍යාපාර→පාරිභෝගික), C2C (පාරිභෝගික↔පාරිභෝගික)

  • EDI — Electronic Data Interchange (ලේඛන ඉලෙක්ට්‍රොනිකව හුවමාරුව)

  • E-payment: credit card, mobile payment, internet banking, digital wallet

🧮 ගණන් කරන Universal ක්‍රම (හැමදාම වැඩ කරන)

පහළ methods ටික ඕනම ප්‍රශ්නයකට වැඩ කරන step-by-step ක්‍රම. සෑම step එකක්ම ලියන්න — steps වලට ලකුණු!

1. Number base පරිවර්තන

🅰️ ඕනම base → Decimal: ඉලක්කම × base^position එකතු කරන්න.
🅱️ Decimal → ඕනම base: බෙදලා ඉතුරු පහළ-සිට-උඩට.
🅲️ Binary → Octal (3-bit) / Hex (4-bit): කඩලා කොටස්වල අගය ලියන්න.

2. 2's Complement (ඍණ සංඛ්‍යා)

ධන අගය → binary → invert → +1. අනිත් ක්‍රම 2: 1's complement = invert only; Sign & Magnitude = මුල් bit = sign.

3. K-map

1 ටික grid එකට → 2/4/8 ගානේ loop → එක loop එකකින් වෙනස් නොවන variables → OR කරන්න.

4. Subnetting

host bits = 32 − prefix → hosts = 2^bits − 2 → block size = 2^bits → network/broadcast/usable ලිපින හොයන්න.

5. Paging (OS)

page = address ÷ pageSize, offset = address % pageSize → page table එකෙන් frame → physical = frame×size + offset.

6. FAT

directory → මුල් block → FAT chain → EOF/−1 දක්වා.

7. Normalization

1NF (atomic) → 2NF (partial dependency අයින්) → 3NF (transitive dependency අයින්).

8. Python trace

Variable table එකක් හදලා, line-by-line අගයන් update කරන්න. Loop ගණන් (range) පරිස්සමෙන්.
